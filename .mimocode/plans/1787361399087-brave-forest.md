## Goal
Refactor the Sessions page from the current layout (global AppSidebar + terminal/panel) to match the mock design's 3-column layout: Left Session Sidebar | Center Chat | Right Workstation.

## Current vs Target Layout

**Current:**
```
App.jsx: AppSidebar (global left) + Sessions (main area)
Sessions: TopBar + (AgentConsole terminal | WorkspacePanel with Files/Changes tabs)
```

**Target (from mock/workspace_preview.html):**
```
App.jsx: Sessions (full width, owns all 3 columns)
Sessions:
┌──────────────────────────────────────────────────────┐
│ TOP BAR: Brand / WorkspaceSwitcher / Branch / Preview+Auto │
├──────────┬───────────────────┬───────────────────────┤
│ LEFT     │ CENTER CHAT      │ RIGHT WORKSTATION     │
│ w-64     │ w-[42%]          │ flex-1                │
│ Sessions │ Chat header      │ Tab bar: 6 tabs       │
│ cards    │ Messages         │ [Tab viewport]        │
│ list     │ Input + Send     │                       │
└──────────┴───────────────────┴───────────────────────┘
```
